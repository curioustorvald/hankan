# ᄒᆞᆫ칸

**ᄒᆞᆫ칸**(hankan)은 각종 기관 등에서 발행하는 `.hwp` 및 `.hwpx` 형식으로 된 양식을 빠르고 정확하게 채우는 웹앱입니다.

**ᄒᆞᆫ칸**은 오직 양식지를 빠르게 작성하려는 목적으로만 개발되었으며, 워드프로세서를 대체할 수 없습니다.


## 사용법 (웹앱)

`webpage-worker/`에 있는 웹앱은 설치 없이 브라우저에서 동작하며, 설치하면
(PWA) 인터넷 없이도 쓸 수 있습니다. 양식 파일과 입력한 내용은 브라우저
안에서만 처리되고 어떤 서버로도 보내지지 않습니다.

1. **양식 열기**로 `.hwp`/`.hwpx` 양식을 엽니다(여러 개 가능, 끌어다 놓아도 됨).
2. 양식의 구조가 화면에 그려지고, 채울 곳마다 입력 칸이 놓입니다.
3. **내 정보**에 성명·주소 등을 적고 **모든 양식에 채우기**를 누르면 열린
   양식 모두의 맞는 칸에 들어갑니다.
4. 입력 칸이 생기지 않는 곳(`OOO`, `20OO. OO. OO.`, `※대량일 경우 뒤쪽 사용`
   같은 자리 표시나 안내문, 아무것도 적히지 않은 칸)은 **글자 직접 고치기**를
   켜고 그 글자를 눌러 고칩니다. 바뀐 글자만 바뀌고 나머지 글자와 모양은
   그대로 남습니다. 빨간색처럼 색이 있는 글자는 화면에도 그 색으로 보이며,
   고치면 검은색이 됩니다.
5. **이 양식 내려받기** 또는 **모든 양식 ZIP으로 받기**로 채운 파일을 받습니다.
6. **여러 명 한꺼번에**에 CSV를 불러오면 한 줄마다 열린 양식을 모두 채워 ZIP으로
   받습니다. 화면에서 채우거나 고친 내용은 모든 파일에 들어갑니다.

**브라우저에 임시저장**을 켜면 열린 양식과 적은 내용이 이 브라우저(IndexedDB)에만
저장되어, 창을 닫았다가 다시 열어도 이어서 할 수 있습니다. 끄면 지워집니다.

```sh
npm run serve:web   # 빌드한 뒤 http://127.0.0.1:8080/ 에서 띄우기
npm run test:web    # 빌드한 뒤 헤드리스 Chromium으로 확인 (provenance/Corpus 필요)
```

Cloudflare Pages 설정(`wrangler.toml`)은 저장소 루트에 있습니다. `npm run build:web`으로
`webpage-worker/public`을 만든 뒤 루트에서 `wrangler pages deploy`만 하면 됩니다.
번들링이나 압축은 하지 않으므로, 올라간 코드가 곧 소스입니다.

## 사용법 (명령줄)

Node.js 21.2 이상이 필요하며, 그 밖에 설치할 것은 없습니다.

```sh
# 양식의 빈칸과 그 이름 보기
node cli/hankan.js --list 입사지원서.hwp

# 양식 하나 × 여러 사람: people.csv의 행마다 하나씩 만들어짐
node cli/hankan.js 입사지원서.hwp people.csv -o out/

# 양식 여러 개 × 내 정보 한 줄: 폴더 안의 양식을 모두 채움
node cli/hankan.js ./채울_양식들 aboutme.csv -o 채운_양식들/
```

데이터는 첫 줄이 열 이름인 CSV(UTF-8 또는 엑셀이 저장하는 CP949) 또는
JSON입니다. 열 이름은 양식에 인쇄된 항목 이름(`성명`, `주소`,
`성명(영문)`)이나 `--list`가 보여 주는 키(`자격증#2`, `t1.r2c3`)로 씁니다.
자주 쓰는 동의어(이름 = 성명, 휴대폰 = 휴대전화 등)도 알아듣습니다.
그냥 `성명`이라고 쓴 열은 대리인·배우자 등 다른 사람의 칸에는 들어가지
않으며, 그런 칸은 `대리인.성명`처럼 이름을 다 적어야 채워집니다.

원본 양식은 바뀌지 않습니다. 결과 파일에서도 값이 들어간 문단만 바뀌고
나머지는 원본과 바이트 단위로 같습니다. 결과 파일은 쓰기 전에 다시 열어
구조를 검사하며, 검사를 통과하지 못하면 쓰지 않습니다.

최대한 그대로 동작하도록 만들고 있지만, 채운 양식의 모양이 틀어질 가능성은
여전히 있습니다. 중요한 문서라면 한컴오피스 뷰어 등 다른 프로그램으로 결과를
꼭 확인하세요.

표의 빈 칸, 누름틀, 그리고 문단 안에 띄어쓰기로 비워 둔 빈칸(`성명:　　　`,
`20  년   월   일`, `(주민등록번호      -       )` 등)을 채웁니다. 날짜 칸에는
`2026-10-09`나 `오늘`처럼, 나뉜 번호 칸에는 `900101-1234567`처럼 씁니다.
체크 상자(□ ☐)는 빈 상자를 채워진 상자(■ ☑)로 바꾸어 표시하고, `[  ]`나
`예(  ) 아니요(  )` 같은 괄호 칸에는 √(또는 양식이 안내하는 표시)를 써넣으며,
양식 개체로 된 체크 상자와 라디오 단추는 선택 상태로 바꿉니다. 값으로는 고를
항목 이름(`있음`, `우편, 팩스`)을 쓰고, 상자가 하나뿐이면 `예`/`Y`를 씁니다.

## 구성

| 경로 | 내용 |
|---|---|
| `engine/` | 문서를 읽고 고치는 엔진 (순수 JS, 의존성 없음, 브라우저와 Node.js 공용) |
| `cli/` | 명령줄 도구 |
| `webpage-worker/` | 웹앱 (`src/`; 빌드 결과는 `public/`) |
| `tools/web/` | 웹앱 빌드, 로컬 서버, 헤드리스 확인 |
| `tools/check/corpus.js` | 코퍼스 전체에 대한 호환성 검사 |
| `PROVENANCE.md` | 각 부분이 어떤 자료에 근거하는지 |

```sh
npm test                    # 단위 테스트
node tools/check/corpus.js  # 코퍼스 호환성 검사 (provenance/Corpus 필요)
node tools/render/make-batch.js            # 렌더링 확인용 채운 양식 묶음 만들기
python3 tools/render/compare.py render-batches/001  # 돌아온 JPEG 비교
```

## 자료의 출처

본 제품은 한글과컴퓨터의 ᄒᆞᆫ글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. 해당 문서 이외의 HWP 관련 자료(오픈소스 파서의 소스 코드 및 문서 등을 포함)는 **일절 참고하지 아니하였습니다**.

개발에 사용된 HWP 양식 코퍼스는 아래의 공개 양식 모음에서 수집되었습니다.
- 국가법령정보센터 Open API (`law.go.kr/licbyl/`, `law.go.kr/admbyl/`, `law.go.kr/ordinbyl/`). 신청서·신고서·동의서·서약서·위임장 등 양식과 관련된 단어로 검색한 결과와, 훈령·예규·고시·공고·조례·규칙 등에 첨부된 양식에서 무작위 추출
- 대법원 전자민원센터 양식모음(`www.scourt.go.kr/nm/minwon/doc/DocListAction.work`). 소장·신청서·진술서 등
- 공공기관 채용정보시스템(`job.alio.go.kr/`). 2020년에서 2025년 사이의 입사지원서·응시원서·자기소개서·경력기술서·서약서·동의서·확인서 등

렌더링 확인용 JPEG 이미지는 **한컴오피스 2024 뷰어**를 사용하여 만들어졌습니다.
